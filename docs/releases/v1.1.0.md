The native port of Sega's 1993 arcade game *SegaSonic The Hedgehog*: not an emulator, but the game's own
program decompiled into C ([segasonic-decomp](https://github.com/cheviman/segasonic-decomp)) and built for
Windows, Linux and macOS.

**No game data is included.** You need your own MAME ROM set: `sonic.zip`, *SegaSonic The Hedgehog*
(Japan, rev. C). Put it beside the game, or drop it on the window the game opens the first time: the game
checks it and takes out what it uses, once.

| System | Package |
|---|---|
| Windows 10 or 11, x64 | `segasonic-windows-x64.zip` |
| Linux, x64 | `segasonic-linux-x64.tar.gz` |
| macOS 11 or later, Apple silicon and Intel | `segasonic-macos-universal.zip` |

What is new since v1.0.0:

- The arcade game is **SegaSonic Arcade** (its executable, .app and window), so the package's two games
  tell apart: **SegaSonic**, the console version, is the one to play. Each package has a `README.txt`
  that says which is which, the first run, the controls and where the files are.
- In SegaSonic the mouse is a pointer until you click in the window: from then on it is player 1's
  trackball. A pause gives the pointer back, and a click takes it again; who plays with keys or a game
  controller keeps the pointer.
- The executables and the macOS apps have an icon of their own (a trackball; nothing of the game's).
- The C the game is built from reads all of the program's data by name, with no number left where a name
  goes, and builds with GCC 15. The game plays the same: its 98 scripted runs still match MAME frame by
  frame, picture and sound.

SDL2 and the C runtime are built into the executables: nothing else to install. The macOS apps are not
signed by a developer: the first time, open one with right click → Open (on macOS 15 and later, try to
open it, then System Settings → Privacy & Security → Open Anyway).

The game was checked frame by frame against MAME, picture and sound, on Windows and Linux; the macOS build
has not been played on a Mac yet: reports are welcome.

Controls, settings and where the game keeps its files: see the [README](https://github.com/cheviman/segasonic-port#readme).
